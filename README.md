# 🎬 Movies Review & Subscriber Analytics Dashboard (V2)

## 📌 Project Overview
An updated, business-focused **Power BI Dashboard** designed to analyze subscriber growth, viewer streaming behavior, genre demand, and content sentiment for a streaming platform. 

This project bridges media operational data and user analytics to deliver actionable insights on device optimization, content acquisition strategies, and subscriber retention.

---

## 🗄️ Core Analytics & Dashboard Features

### 1. Key Performance Indicators (KPIs)
* **Active User Base**: Live tracking of overall active subscribers (15K Active Users).

### 2. Device Engagement & Streaming Metrics
* **Watch Hours by Device**: Analyzed overall watch volume across platform devices, identifying **Smart TV** (~60M watch hours) and **Mobile** as primary consumption channels compared to Laptop, Tablet, Game Console, and Streaming Stick.

### 3. Content & Genre Performance
* **Top 10 Movies by Watch Hours**: Evaluated engagement per title, pinpointing top-performing content led by *Gilded Throne* and *The Shadows of...*.
* **Genre Distribution**: Cataloged primary genres (**Thriller**, **Romance**, **Sci-Fi**, **Reality**, and **Stand-Up**) to evaluate catalog diversity and localized streaming preferences.
* **Content Localization**: Tracked streaming title distribution by language, led by **Spanish** and **Portuguese**.

### 4. Audience Sentiment & Growth Trends
* **User Sentiment Analysis**: Categorized customer reviews into **Positive**, **Neutral**, and **Negative** ratings, showing strong overall user satisfaction.
* **10-Year Subscriber Growth (2016–2026)**: Tracked historical user acquisition over time to monitor long-term platform adoption trends.

### 5. Multi-Dimensional Interactive Slicers
* **Subscription Tiers**: Filter analytics by **Basic with Ads**, **Standard**, and **Premium** plans.
* **Device Profiling**: Cross-filter report visuals by hardware type.
* **Demographics & Timeline**: Filter insights by **Gender** and **Subscriber Signup Date**.

---

## 🛠️ Tech Stack & Implementation
* **Tool**: Power BI Desktop
* **Data Modeling**: Power Query (ETL), DAX Measures & Aggregations
* **Visuals Used**: Custom Bar Charts, Column Charts, KPI Cards, Vertical Slicers
